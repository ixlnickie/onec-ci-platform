# Использование вспомогательных инструментов

В ходе работы над проектом отдельные инструменты на основе искусственного интеллекта использовались в качестве вспомогательного средства.

| Направление | Описание |
| --- | --- |
| Цель использования | Получение справочной информации, уточнение отдельных технических вопросов и помощь при подготовке черновиков документации |
| Инструмент | ChatGPT |
| Область применения | Обсуждение возможных вариантов реализации, анализ отдельных фрагментов конфигураций и скриптов, формулирование и редактирование текстов документации |
| Результаты использования | Отдельные предложения, пояснения и черновые варианты материалов, которые рассматривались командой |
| Работа команды | Проектирование, разработка, настройка, проверка решений, внесение изменений, тестирование и принятие итоговых технических решений выполнялись участниками команды |
| Проверка результатов | Предложения и материалы проверялись и корректировались участниками команды перед использованием |
