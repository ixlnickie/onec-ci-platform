# onec-ci-platform — CI/CD-платформа для конфигураций 1С

## О проекте

Проект УрФУ по разработке CI/CD-среды для автоматизации процессов проверки, сборки и сопровождения конфигураций 1С.

В целевой архитектуре предусматривается использование GitLab, GitLab Runner, SonarQube (BSL) и 1C:EDT. Развёртывание инфраструктуры планируется на VPS. На текущем этапе выполняется подготовка к настройке и запуску компонентов. Их работоспособность будет подтверждена после развёртывания и проведения испытаний.

Этот репозиторий содержит инфраструктурные конфигурации, вспомогательные скрипты и документацию проекта. Репозиторий с конфигурацией 1С планируется разместить отдельно в GitLab.

## Текущий статус

Проект находится на этапе разработки и подготовки инфраструктуры к развёртыванию. Наличие описания компонента в документации не означает, что он уже установлен и функционирует.

Актуальное состояние реализации требований представлено в документе [Статус требований](docs/requirements-status.md).

## Структура репозитория

- `ci/` — конфигурация и скрипты CI.
- `docs/` — документация проекта.
- `docs/diagrams/` — каталог для архитектурных схем.
- `docs/evidence/` — материалы и результаты проверок.
- `presentation/` — материалы презентации проекта.

Ссылка на доску задач будет добавлена после её создания и настройки доступа.

## Правила работы


- Работа над изменениями ведётся через Issues и Pull Requests.
- Изменения проходят проверку перед объединением с основной веткой.
- Секреты, дистрибутивы и лицензии 1С не должны попадать в репозиторий.
- Конфигурационные параметры и чувствительные данные хранятся отдельно от исходного кода.
