# Шаблон проекта конфигурации 1С (EDT)

Проект создаётся в GitLab через **New project → Create from template → Instance →
«Конфигурация 1С (EDT)»**. После создания в нём уже есть:

- структура каталогов для исходников EDT;
- `.gitlab-ci.yml`, который подключает центральный pipeline (свой пайплайн писать не нужно);
- настройки статического анализа: `.bsl-language-server.json`, `sonar-project.properties`;
- `.editorconfig` и `.gitignore`;
- `ci/scripts/` — скрипты сборки/тестов/деплоя (подкладываются при провижининге).

## Что делать после создания

1. Клонировать проект и открыть его в **1C:EDT** (File → Import → Existing Projects).
2. Положить конфигурацию в `src/` (см. `src/README.md`).
3. Работать в ветках `feature/<номер-задачи>-<кратко>` от `main`, изменения — через Merge Request.
4. Смотреть результат в GitLab: **Build → Pipelines**, **Merge Request → стадии**.

## Pipeline

| Стадия        | Что делает                            | Где                          |
| ------------- | ------------------------------------- | ---------------------------- |
| `lint`        | BSL-анализ и quality gate в SonarQube | docker-раннер                |
| `build`       | сборка `.cf` из исходников EDT        | раннер `onec` (платформа 1С) |
| `test`        | автотесты на тестовой ИБ              | раннер `onec`                |
| `artifact`    | версионируемый артефакт               | раннер `onec`                |
| `deploy-test` | обновление тестового контура          | раннер `onec`                |
| `deploy-prod` | обновление прода (вручную, с бэкапом) | раннер `onec`                |

Пока на стенде нет платформы 1С, работают только `lint`, а стадии `onec`
выключены переменной `ONEC_ENABLED=false`. Когда платформа появится на раннере,
переменная включается на уровне группы — pipeline начнёт собирать и тестировать.

## Переменные

Наследуются от группы `onec-platform` (`SONAR_HOST_URL`, `SONAR_TOKEN`,
`ONEC_ENABLED`, `ONEC_CONFIG_PATH`). Персональные переменные проекта проставляет
сервис автодонастройки при создании репозитория.
